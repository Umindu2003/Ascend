# 🚀 Ascend

### Level Up Your Real Life.

Ascend is a gamified self-improvement mobile application designed to transform daily habits and goals into an exciting progression system.

Inspired by RPG games and competitive racing, Ascend helps users build consistency, track personal growth, and stay motivated by turning everyday achievements into XP, levels, streaks, and rewards.

> Your life is the game. Every day is a new level. 🎮

---

## ✨ Features

### 🎯 Mission-Based Habit System

* Create personal missions and daily goals
* Complete tasks to earn XP
* Track progress over time
* Build positive routines

### ⚡ XP & Level Progression

* Earn experience points from completed missions
* Level up your profile
* Track your personal growth journey

### 🔥 Streak & Combo System

* Maintain daily consistency
* Protect your streak
* Build momentum through continuous progress

### 🏆 Achievement System

Unlock achievements based on your progress:

* First Mission Completed
* 7 Day Streak
* XP Master
* Consistency Champion
* Goal Crusher

### 📊 Personal Dashboard

View your:

* Current level
* Total XP
* Completed missions
* Streak history
* Achievement progress

### 🌙 Modern Gen Z UI

* Dark mode inspired design
* Smooth animations
* Gaming-style interactions
* Clean and minimal experience

# 🎨 Design Philosophy

Ascend is built around one idea:

> Small improvements every day create extraordinary results.

Instead of forcing users to change overnight, Ascend focuses on consistency, motivation, and making self-improvement enjoyable.

# 📌 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/ascend.git
```

Install dependencies:

```bash
npm install
```

Start Expo:

```bash
npx expo start
```

---

# 🔐 Environment Setup

Create a Firebase project and add your configuration:

```
FIREBASE_API_KEY=
FIREBASE_AUTH_DOMAIN=
FIREBASE_PROJECT_ID=
FIREBASE_STORAGE_BUCKET=
FIREBASE_MESSAGING_SENDER_ID=
FIREBASE_APP_ID=
```
